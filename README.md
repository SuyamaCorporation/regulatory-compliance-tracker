# Industry Regulatory Compliance Tracker

**Category:** Business & Legal Tools

Pre-loaded checklists for HIPAA, GDPR, SOX, FDA 21 CFR Part 11, and ISO 27001 frameworks. Track compliance status per item, set audit dates and document versions, get alerts for upcoming and overdue reviews (30/60-day windows), and manage remediation tasks with priority levels and deadlines. Add custom items for any framework. All data persists in localStorage.
